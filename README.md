# ryzha

Orange and peppermint flavored dark theme.

> Based on [Vesper](https://github.com/raunofreiberg/vesper) by [raunofreiberg](https://github.com/raunofreiberg).

## Installation
1. Clone the repository:
   ```bash
   git clone 370rokas/ryzha
   ```

2. Run `install.sh` for desired applications:
   ```bash
   ./ryzha/(Application name)/install.sh

    # Example for Ghostty:
    ./ryzha/ghostty/install.sh

   ```

(?) To uninstall, run `install.sh` with `uninstall` argument:
   ```bash
   ./ryzha/(Application name)/install.sh uninstall

    # Example for Ghostty:
    ./ryzha/ghostty/install.sh uninstall
   ```

## Supported Applications
- [Ghostty](./ryzha/ghostty)
- [nano](./ryzha/nano)
